# Kontrollprotokoll Web-App

Diese Dateien gemeinsam auf einem HTTPS-Webspace veröffentlichen. Danach `index.html` über Safari, Chrome oder Edge öffnen.

Wichtig:
- Nicht die HTML-Datei einzeln per Messenger oder Dateien-App öffnen.
- Service Worker und Offline-Nutzung funktionieren nur über HTTPS oder localhost.
- Auf iPhone/iPad: Safari → Teilen → „Zum Home-Bildschirm“.
- Auf Android: Chrome → Menü → „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Enthalten:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/
